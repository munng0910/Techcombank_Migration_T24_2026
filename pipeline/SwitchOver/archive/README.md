# Historical references

The versioned operational Jenkinsfile, startup-reference Jenkinsfile and original failover script are not maintained entry points for this module. Their unmodified copies are preserved under ignored `../local/originals/jenkins/` and `../local/originals/scripts/`, along with the original startup material under `../local/originals/orig/`.

They are intentionally not committed here: historical copies, prompts and captured output have not been qualified for publication. Any future historical reference added to this directory must be reviewed and sanitized first. Use Git history rather than version-suffixed copies for future maintained revisions.
